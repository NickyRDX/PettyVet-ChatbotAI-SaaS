# Landing PettyVet — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construir la landing pública de PettyVet (9 secciones) que lleva a la clínica visitante a pedir una demo por WhatsApp.

**Architecture:** Server Components por defecto; solo 6 islas cliente (`ScrollAwareHeader`, `MobileMenu`, `HeroChat`, `FeatureTabs`, `StepsLine`, `Reveal`). Todo el texto y los datos viven en `lib/landing/content.ts` tipado por `lib/landing/types.ts`; los componentes son presentacionales y reciben datos por props. GSAP se registra una vez en `lib/gsap.ts` y siempre corre dentro de `gsap.matchMedia("(prefers-reduced-motion: no-preference)")`.

**Tech Stack:** Next.js 16.3 (App Router), React 19.2, TypeScript 5 strict, Tailwind CSS v4 (`@theme inline`), GSAP 3.15 + `@gsap/react` 2.1, `@base-ui/react` (Tabs), `lucide-react` 1.x, `class-variance-authority`, `cn`. Tests de lógica con `node --test` (Node 24, type-stripping nativo). Verificación visual con Playwright MCP.

**Spec:** `docs/superpowers/specs/2026-10-07-landing-design.md`

## Global Constraints

- Idioma de toda la UI: español rioplatense (voseo: "Probá", "Escribinos").
- Nada de cifras, clientes, testimonios ni precios inventados: todo dato desconocido se muestra como placeholder visible (badge "Placeholder"/"Precio a definir"/"Respuesta provisoria") y vive en `lib/landing/content.ts`.
- Contraste AA, foco visible, objetivos táctiles ≥ 44px (`h-11`/`size-11` mínimo), HTML semántico, todo operable con teclado.
- Responsive desde 320px sin scroll horizontal.
- `prefers-reduced-motion: reduce` ⇒ ninguna animación GSAP; todo el contenido visible en su estado final.
- Solo tema claro. Tokens: `ink #14203A`, `paper #FAF8F5`, `surface #FFFFFF`, `line #E9E4DC`, `accent #FF7A59` (siempre con texto `ink` encima; nunca texto coral sobre `paper`), `whatsapp #25D366`, `muted-foreground #5B6475`.
- Fuentes: Bricolage Grotesque (títulos, `font-heading`) + Geist (texto). Vía `next/font/google`.
- Server Components por defecto; `"use client"` solo en los 6 archivos listados en Architecture.
- Ningún componente contiene copy de producto hardcodeado (sí se permiten labels de accesibilidad genéricos).
- GSAP: `useGSAP({ scope })`, solo animar `transform`/`opacity`/colores puntuales.
- Antes de usar cualquier API de Next leer la guía en `node_modules/next/dist/docs/` (AGENTS.md).
- Links de WhatsApp: `https://wa.me/<dígitos>?text=<encodeURIComponent(msg)>`, `target="_blank"`, `rel="noopener noreferrer"`.

## Review Focus

1. **Viewport de 320px** — el H1, los tabs, la grilla de precios y el chat no deben provocar scroll horizontal (`scrollWidth <= innerWidth`). Test en Task 9, paso de verificación 320px.
2. **Reduced motion** — con `prefers-reduced-motion: reduce` ningún elemento de `<main>` queda con `opacity: 0` o `visibility: hidden` (salvo el indicador "escribiendo"). Test en Task 9.
3. **Mensajes de WhatsApp con caracteres especiales** (ñ, ¿, emoji, `&`, `#`, saltos de línea) y números con `+`, espacios o guiones — la URL debe abrir el mensaje exacto. Test unitario en Task 2.
4. **Menú móvil abierto + resize a desktop / click en un link / Esc** — el panel se cierra y no queda abierto invisible; con Esc el foco vuelve al botón. Test en Task 4.
5. **"Ver de nuevo" en medio de la animación del hero** — reinicia sin duplicar burbujas ni dejar la tarjeta a mitad de camino; sin JS el chat se ve completo. Test en Task 5.

const MIN_DIGITS = 8;

/** Arma un link de WhatsApp con un mensaje prearmado. */
export function buildWhatsAppUrl(phone: string, message: string): string {
  const digits = phone.replace(/\D/g, "");
  if (digits.length < MIN_DIGITS) {
    throw new Error(`WhatsApp number must have at least ${MIN_DIGITS} digits`);
  }
  return `https://wa.me/${digits}?text=${encodeURIComponent(message)}`;
}
```

"use client";

import { useRef, type ReactNode } from "react";
import { gsap, MOTION, MOTION_OK, useGSAP } from "@/lib/gsap";

type RevealProps = {
  children: ReactNode;
  className?: string;
  /** Selector de hijos a animar en cascada (ej. "[data-reveal]"). */
  items?: string;
  delay?: number;
};

export function Reveal({ children, className, items, delay = 0 }: RevealProps) {
  const ref = useRef<HTMLDivElement>(null);

  useGSAP(
    () => {
      const el = ref.current;
      if (!el) return;
      const mm = gsap.matchMedia();
      mm.add(MOTION_OK, () => {
        const targets = items ? gsap.utils.toArray<HTMLElement>(items, el) : el;
        gsap.from(targets, {
          autoAlpha: 0,
          y: MOTION.y,
          duration: MOTION.duration,
          ease: MOTION.ease,
          stagger: items ? MOTION.stagger : 0,
          delay,
          scrollTrigger: { trigger: el, start: "top 85%", once: true },
        });
      });
      return () => mm.revert();
    },
    { scope: ref },
  );

  return (
    <div ref={ref} className={className}>
      {children}
    </div>
  );
}
```

"use client";

import { useEffect, useState, type ReactNode } from "react";

const THRESHOLD = 24;

export function ScrollAwareHeader({ children }: { children: ReactNode }) {
  const [scrolled, setScrolled] = useState(false);

  useEffect(() => {
    const onScroll = () => setScrolled(window.scrollY > THRESHOLD);
    onScroll();
    window.addEventListener("scroll", onScroll, { passive: true });
    return () => window.removeEventListener("scroll", onScroll);
  }, []);

  return (
    <header
      data-scrolled={scrolled}
      className="group/nav sticky top-0 z-50 px-3 pt-3 sm:px-4 sm:pt-4"
    >
      {children}
    </header>
  );
}

"use client";

import { useCallback, useEffect, useId, useRef, useState } from "react";
import { Menu, X } from "lucide-react";
import { buttonVariants } from "@/components/ui/button";
import type { NavLink } from "@/lib/landing/types";

type MobileMenuProps = {
  links: readonly NavLink[];
  cta: { label: string; href: string };
};

export function MobileMenu({ links, cta }: MobileMenuProps) {
  const [open, setOpen] = useState(false);
  const buttonRef = useRef<HTMLButtonElement>(null);
  const panelRef = useRef<HTMLDivElement>(null);
  const panelId = useId();

  const close = useCallback((restoreFocus: boolean) => {
    setOpen(false);
    if (restoreFocus) buttonRef.current?.focus();
  }, []);

  useEffect(() => {
    if (!open) return;
    const desktop = window.matchMedia("(min-width: 768px)");
    const onKey = (e: KeyboardEvent) => {
      if (e.key === "Escape") close(true);
    };
    const onPointer = (e: PointerEvent) => {
      const target = e.target as Node;
      if (!panelRef.current?.contains(target) && !buttonRef.current?.contains(target)) {
        close(false);
      }
    };
    const onDesktop = () => {
      if (desktop.matches) close(false);
    };
    document.addEventListener("keydown", onKey);
    document.addEventListener("pointerdown", onPointer);
    desktop.addEventListener("change", onDesktop);
    panelRef.current?.querySelector<HTMLElement>("a")?.focus();
    return () => {
      document.removeEventListener("keydown", onKey);
      document.removeEventListener("pointerdown", onPointer);
      desktop.removeEventListener("change", onDesktop);
    };
  }, [open, close]);

  return (
    <div className="md:hidden">
      <button
        ref={buttonRef}
        type="button"
        aria-expanded={open}
        aria-controls={panelId}
        aria-label={open ? "Cerrar menú" : "Abrir menú"}
        onClick={() => setOpen((v) => !v)}
        className="inline-flex size-11 items-center justify-center rounded-full text-ink hover:bg-muted"
      >
        {open ? <X className="size-5" aria-hidden /> : <Menu className="size-5" aria-hidden />}
      </button>

      <div
        ref={panelRef}
        id={panelId}
        hidden={!open}
        className="absolute inset-x-0 top-full mt-2 rounded-card border border-line bg-surface p-3 shadow-xl shadow-ink/5"

        <nav aria-label="Principal (móvil)">
          <ul className="flex flex-col">
            {links.map((link) => (
              <li key={link.href}>
                <a
                  href={link.href}
                  onClick={() => close(false)}
                  className="flex min-h-11 items-center rounded-xl px-3 text-base text-ink hover:bg-muted"

                  {link.label}
                </a>
              </li>

import { useRef } from "react";
import { RotateCcw, Siren, Sparkles } from "lucide-react";
import { cn } from "@/lib/utils";
import { gsap, MOTION_OK, useGSAP } from "@/lib/gsap";
import type { HeroChatContent } from "@/lib/landing/types";
import { BookedCard } from "./BookedCard";
import { ChatBubble } from "./ChatBubble";
import { MiniAgenda } from "./MiniAgenda";

const INK = "#14203A";
const WHITE = "#FFFFFF";

type HeroChatProps = { chat: HeroChatContent };

export function HeroChat({ chat }: HeroChatProps) {
  const root = useRef<HTMLDivElement>(null);
  const timeline = useRef<gsap.core.Timeline | null>(null);
  const [m1, m2, m3, m4] = chat.messages;

  useGSAP(
    () => {
      const el = root.current;
      if (!el) return;
      const mm = gsap.matchMedia();

      mm.add(MOTION_OK, () => {
        const q = gsap.utils.selector(el);
        const items = q("[data-chat]");
        const typing = q("[data-typing]");
        const dots = q("[data-dot]");
        const chip = q("[data-slot-selected]");
        const booked = q("[data-chat='booked']");
        const target = q("[data-agenda-target]");

        const hidden = () => {
          gsap.set(items, { autoAlpha: 0, y: 12 });
          gsap.set(booked, { x: -48, y: 64, scale: 0.85, rotate: -8 });
          gsap.set(chip, { backgroundColor: WHITE, color: INK });
          gsap.set(typing, { autoAlpha: 0 });
          gsap.set(target, { scale: 1 });
        };
        hidden();
        el.removeAttribute("data-chat-pending");

        const show = (sel: string) => ({
          targets: q(`[data-chat='${sel}']`),
          vars: { autoAlpha: 1, y: 0, duration: 0.45, ease: "power3.out" },
        });
        const typingFor = (hold: number) =>
          gsap
            .timeline()
            .to(typing, { autoAlpha: 1, duration: 0.2 })
            .fromTo(
              dots,
              { y: 0 },
              { y: -3, duration: 0.3, ease: "sine.inOut", yoyo: true, repeat: Math.round(hold / 0.3), stagger: 0.1 },
            )
            .to(typing, { autoAlpha: 0, duration: 0.15 });

        const step = (sel: string) => {
          const s = show(sel);
          return gsap.to(s.targets, s.vars);
        };

        const tl = gsap.timeline({ delay: 0.6 });
        tl.add(hidden, 0)
          .add(step("m1"))
          .add(typingFor(1.2), "+=0.3")
          .add(step("flag"))
          .add(step("m2"), "<0.15")
          .add(step("slots"), "<0.2")
          .to(chip, { scale: 0.92, duration: 0.12 }, "+=0.7")
          .to(chip, { scale: 1, backgroundColor: INK, color: WHITE, duration: 0.2 })
          .add(step("m3"), "+=0.2")
          .add(typingFor(0.9), "+=0.3")
          .add(step("m4"))
          .to(booked, { autoAlpha: 1, x: 0, y: 0, scale: 1, rotate: 2, duration: 0.8, ease: "back.out(1.6)" }, "+=0.3")
          .to(target, { scale: 1.04, duration: 0.18, yoyo: true, repeat: 1 }, "<0.5");

        timeline.current = tl;
        return () => {
          timeline.current = null;
        };
      });

      return () => mm.revert();
    },
    { scope: root },
  );

  return (
    <div ref={root} data-chat-pending="" className="relative mx-auto w-full max-w-[520px] pb-16 sm:pb-6">
      <noscript>
        <style>{`[data-chat-pending] [data-chat]{visibility:visible}`}</style>
      </noscript>
      <p className="sr-only">{chat.srSummary}</p>

      <MiniAgenda
        title={chat.agenda.title}
        rows={chat.agenda.rows}
        className="absolute top-20 right-0 hidden w-[230px] rotate-2 sm:block"
      />

      {/* Teléfono */}
      <div aria-hidden="true" className="relative z-10 mx-auto w-[300px] sm:mx-0 sm:w-[320px]">
        <div className="rounded-[44px] bg-ink p-2.5 shadow-2xl shadow-ink/30">
          <div className="flex h-[540px] flex-col overflow-hidden rounded-[36px] bg-chat">
            <div className="flex items-center gap-3 bg-whatsapp-dark px-4 pt-7 pb-3 text-white">
              <span className="inline-flex size-9 items-center justify-center rounded-full bg-white/20 text-sm font-semibold">
                {chat.contactName.charAt(0)}
              </span>
              <div className="leading-tight">
                <p className="text-sm font-semibold">{chat.contactName}</p>
                <p className="text-xs text-white/80">{chat.contactStatus}</p>
              </div>
            </div>

            <div className="relative flex flex-1 flex-col gap-2 px-3 py-4">
              <ChatBubble data-chat="m1" from={m1.from} text={m1.text} time={m1.time} />
              <span
                data-chat="flag"
                className="inline-flex items-center gap-1.5 self-center rounded-full bg-accent px-3 py-1 text-[11px] font-semibold text-ink"
              >
                <Siren className="size-3.5" aria-hidden /> {chat.priorityLabel}
              </span>
              <ChatBubble data-chat="m2" from={m2.from} text={m2.text} time={m2.time} assistantLabel={chat.assistantLabel} />
              <div data-chat="slots" className="flex gap-2 self-end">
                {chat.slots.map((slot) => {
                  const selected = slot === chat.selectedSlot;
                  return (
                    <span
                      key={slot}
                      data-slot-selected={selected ? "" : undefined}
                      className={cn(
                        "rounded-full border border-whatsapp-dark/30 px-3 py-1 text-xs font-medium tabular-nums",
                        selected ? "bg-ink text-white" : "bg-surface text-ink",
                      )}
                    >
                      {slot}

              </div>

export function StepsLine() {
  const ref = useRef<HTMLDivElement>(null);
  const fill = useRef<HTMLDivElement>(null);

  useGSAP(
    () => {
      const mm = gsap.matchMedia();
      mm.add(MOTION_OK, () => {
        gsap.fromTo(
          fill.current,
          { scaleX: 0 },
          {
            scaleX: 1,
            ease: "none",
            scrollTrigger: { trigger: ref.current, start: "top 80%", end: "top 35%", scrub: true },
          },
        );
      });
      return () => mm.revert();
    },
    { scope: ref },
  );

  return (
    <div ref={ref} aria-hidden className="absolute top-6 right-[16%] left-[16%] hidden h-px bg-line md:block">
      <div ref={fill} className="h-full origin-left bg-ink" />
    </div>
  );
}

# Landing de PettyVet — mapa

## ¿Dónde edito…?

| Quiero cambiar… | Archivo |
|---|---|
| Cualquier texto, precio, pregunta o el número de WhatsApp | `lib/landing/content.ts` |
| Los tipos de esos datos | `lib/landing/types.ts` |
| Colores, tipografías, radios | `app/globals.css` (`:root` y `@theme inline`) |
| El orden de las secciones | `app/page.tsx` |

## Secciones (`components/landing/`)

Una carpeta = un bloque de la página. Cada una exporta su componente por `index.ts`.

| Carpeta | Qué es | ¿Usa JS en el navegador? |
|---|---|---|
| `Navbar/` | Barra superior + menú móvil | Sí: `ScrollAwareHeader`, `MobileMenu` |
| `Hero/` | Titular + chat de WhatsApp animado | Sí: `HeroChat` |
| `PainPoints/` | "Antes → con PettyVet" | No |
| `Features/` | Tabs de funciones + `mockups/` | Sí: `FeatureTabs` |
| `HowItWorks/` | Tres pasos | Sí: `StepsLine` |
| `Pricing/` | Planes | No |
| `Faq/` | Preguntas (`<details>` nativo) | No |
| `FinalCta/` | Bloque azul final | No |
| `Footer/` | Pie | No |

## Piezas compartidas

- `components/ui/` — `Button` (shadcn), `Container`, `Badge`, `SectionHeading`, `Logo`.
- `components/motion/Reveal.tsx` — envolvé cualquier bloque para que aparezca al hacer scroll. Con `items="[data-reveal]"` anima en cascada los hijos marcados con `data-reveal`.
- `lib/gsap.ts` — registra GSAP una sola vez. Todas las animaciones corren solo si el usuario no pidió "reducir movimiento".

## Reglas

1. Los componentes no tienen texto escrito adentro: lo reciben de `content.ts`.
2. Solo se agrega `"use client"` cuando hay estado, eventos o GSAP.
3. Nada de cifras o clientes inventados: si falta el dato, va con badge de placeholder.

## Comandos

- `pnpm dev` — servidor local
- `pnpm test` — tests de contenido y links de WhatsApp
- `pnpm lint` / `pnpm build`
